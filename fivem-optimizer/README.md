# FiveM Optimizer

أداة لويندوز بتظبط الجهاز للعب FiveM لما يكون المعالج هو اللي خانق الفريمات.
بتعمل كل اللي الويندوز المخفف بيعمله، وفوقه حاجات هو مش بيعملها، **من غير ما تسطّب ويندوز جديد**.
كل حاجة بتتغير بيتاخدلها نسخة احتياطية الأول، وتقدر ترجّع كله بضغطة واحدة.

## ليه أحسن من ويندوز مخفف (Tiny11 / Atlas / ReviOS)؟

| | ويندوز مخفف | FiveM Optimizer |
|---|:-:|:-:|
| يقفل التليميتري والخدمات اللي ملهاش لازمة | ✅ | ✅ |
| خطة طاقة من غير ركن للأنوية | ✅ | ✅ ومعاها تفضيل الأنوية السريعة (P-cores) |
| يقفل Memory Integrity / VBS (من 5 لـ 15% فريمات على ويندوز 11) | أحياناً | ✅ |
| يثبت FiveM على الأنوية السريعة بتاعة الـ i5-14400F | ❌ | ✅ |
| Timer 0.5ms عشان الفريمات تبقى أنعم | ❌ | ✅ |
| ينضّف الرام أوتوماتيك وانت بتلعب (زي ISLC) | ❌ | ✅ |
| يظبط إعدادات جرافيكس FiveM اللي بتتقل على المعالج | ❌ | ✅ |
| ينقل إعدادات صاحبك لجهازك | ❌ | ✅ |
| Windows Update والـ Defender والـ anti-cheat شغالين عادي | ⚠️ غالباً بيبوظوا | ✅ |
| ترجع كل حاجة زي ما كانت | ❌ لازم تسطّب ويندوز من الأول | ✅ ضغطة واحدة |

## صحابك بنفس مواصفاتك وبيجيبوا 100؟

يبقى الفرق في السوفت وير والإعدادات، مش في الجهاز. أكتر 4 أسباب شائعة:

1. **Memory Integrity مقفول عندهم.** الويندوز 11 لما بيتسطّب جديد بيشغّله لوحده، فاللي ويندوزه قديم أو مترقّي من 10 غالباً مقفول عنده. ← خيار **3**
2. **إعدادات اللعبة.** ← خيار **5**: خلّي صاحبك يبعتلك ملف الإعدادات بتاعه وانقله عندك.
3. **XMP شغال عندهم والرام قطعتين.** خيار **1** هيقولك وضعك.
4. **الرام فاضية عندهم.** عندك 80% مليانة قبل ما تلعب. ← خيار **7** والـ Booster.

## طريقة الاستخدام

1. نزّل فولدر `fivem-optimizer` كله على الويندوز.
2. دبل كليك على **`Start-Optimizer.bat`** ووافق على صلاحية الأدمن.
3. امشي بالترتيب ده:

| الخيار | بيعمل إيه |
|---|---|
| **1** فحص | بيكشف Memory Integrity، والرام (Dual Channel؟ XMP؟)، والـ BIOS، والخدمات الشغالة، وإعدادات FiveM عندك، والبرامج اللي واكلة رام |
| **2** Optimize Windows | خطة طاقة Ultimate من غير ركن للأنوية ومفضّلة الأنوية السريعة. بيقفل 13 خدمة (التليميتري، SysMain، فهرسة البحث، ...) ومهام التليميتري و Game DVR و Widgets والأنيميشن والشفافية. وبيشغّل Game Mode و Hardware GPU Scheduling، وبيدّي اللعبة أولوية في المعالج |
| **3** Memory Integrity | بيقفل VBS/HVCI. **ده أكبر مكسب على ويندوز 11.** |
| **4** CPU-light preset | بيقلل في ملف إعدادات FiveM الحاجات اللي بتتقل على المعالج بس: Population وDistance Scaling وExtended Distance وLong Shadows وHigh Detail Streaming وGrass |
| **5** Import | تنقل ملف إعدادات صاحبك لجهازك، مع الاحتفاظ بالريزوليوشن والشاشة وكارت الشاشة بتوعك |
| **6** Startup | تختار البرامج اللي متشتغلش مع الويندوز |
| **7** Close apps | تقفل البرامج التقيلة قبل ما تلعب |
| **8** Clean | بيمسح كاش FiveM والـ Temp والـ shader cache |
| **B** **Game Booster** | **سيبه مفتوح وانت بتلعب.** بيدّي FiveM أولوية High، ويثبته على الأنوية السريعة، ويودّي Discord والمتصفح على الأنوية الموفرة، ويشغّل Timer 0.5ms، وينضّف الرام أوتوماتيك لما تقرب تخلص |
| **9** Restore | بيرجّع كل اللي فوق زي ما كان |

بعد خيار **2** وخيار **3** اعمل **Restart**، وبعدين شغّل خيار **1** تاني عشان تتأكد إن كل حاجة اتطبقت.

### ملف إعدادات صاحبك

صاحبك يدوس `Win + R` ويكتب:

```
%APPDATA%\CitizenFX
```

ويبعتلك ملف **`gta5_settings.xml`**. بعدها تختار خيار **5** وتسحب الملف جوه الشاشة.

## حاجات برا الأداة بتفرق برضو

- **NVIDIA Control Panel:** حط Low Latency Mode = On، وPower management = Prefer maximum performance، وMax Frame Rate أقل بـ 3 من ريفريش الشاشة.
- **Discord:** اقفل Hardware Acceleration والـ Overlay.
- **F8 في FiveM واكتب `resmon 1`:** لو سكريبت من السيرفر واكل أكتر من 1–2ms، يبقى السيرفر هو اللي تقيل مش جهازك.
- **الـ BIOS:** فعّل XMP، وثبّت آخر إصدار للمازربورد.

## الأمان

- السكريبت مش بيمسح أي جزء من ويندوز. الخدمات بتتقفل بس (Disabled)، مش بتتشال.
- النسخة الاحتياطية في `C:\ProgramData\FiveMOptimizer\`.
- لو anti-cheat في لعبة تانية (Valorant أو FACEIT) طلب Memory Integrity، خيار **9** بيرجّعه.
- الـ Booster بيرجّع البرامج التانية وTimer الويندوز لطبيعتهم لما تدوس `Q`.
